# API Inspector

A free, lightweight API testing and JSON inspection tool for developers.

## 🚀 Live Demo

[https://api-inspector-tool.vercel.app](https://api-inspector-tool.vercel.app/)

## 📌 About

API Inspector is a simple browser-based developer utility that allows you to enter an API endpoint and inspect its response.

The project was built as a practical JavaScript project while learning HTTP requests, JSON, DOM manipulation, and API integration.

## ✨ Features

- Test API endpoints
- Send API requests from the browser
- View API responses
- Inspect JSON responses
- Simple and lightweight interface
- Developer-focused UI
- No account required
- Free to use

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- XMLHttpRequest
- JSON
- DOM API

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/syedrasimali/api-inspector.git
```

Open the project folder:

```bash
cd api-inspector
```

Then open `index.html` in your browser.

You can also use VS Code Live Server for local development.

## ⚠️ CORS

Some APIs may not work directly from the browser because of CORS restrictions.

If an API does not allow requests from your website's origin, the browser may block the request even though the API itself is working.
